# 爆款标题模式

标题要短、具体、有画面感。优先让用户一眼知道照片的情绪、风格或场景，不使用虚假夸张承诺。

## 标题原则

- 控制在 8-22 个中文字符。
- 少用感叹号和堆砌形容词。
- 不写“全网最”“天花板”“封神级”等低可信表达。
- 标题和图片要强相关。
- 可以保留一点留白，让读者愿意点开看图。

## 1. 情绪型

适合安静、温柔、清冷、文艺、居家图片。

模板：

- 今天只想慢一点
- 风把情绪吹得很轻
- 有些照片不用说太多
- 这一刻刚好很安静
- 把温柔留给今天

## 2. 场景型

适合咖啡馆、街拍、窗边、旅行、居家图片。

模板：

- 下午三点的窗边光
- 在咖啡馆偷到一点松弛
- 今天的街角很好拍
- 周末就该这样慢慢过
- 这组照片有旧电影感

## 3. 穿搭型

适合穿搭、通勤、出街、OOTD 图片。

模板：

- 今天这套有点松弛
- 简简单单也很有质感
- 最近喜欢这种低饱和穿搭
- 不费力的出门搭配
- 一套适合被记录的日常

## 4. 人设型

适合有明显个人气质的图片，但不要虚构职业、身份或生活经历。

模板：

- 一个慢热的人也有自己的光
- 不太会表达，但很会感受
- 看起来安静，其实很自由
- 不用很用力，也可以很好看
- 把自己过成舒服的样子

## 5. 反差型

适合酷飒、街头、甜酷、极简图片。

模板：

- 今天不想太乖
- 甜一点，也酷一点
- 温柔里藏了一点锋利
- 没有笑，也很有状态
- 简单穿，但不简单

## 6. 收藏型

适合用户明确要“爆款标题”“收藏率标题”时使用。

模板：

- 这组拍照姿势可以存
- 氛围感照片这样写文案
- 普通照片也能有故事感
- 这类标题真的很适合配图
- 穿搭照配文可以这样写

## 标题生成步骤

1. 先判断图片主风格：温柔、治愈、极简、甜美、酷飒、复古、清透、日常。
2. 选择 2-3 种标题模式混合生成。
3. 每个标题只表达一个核心点。
4. 最终给 5 个备选，避免重复同一语义。
